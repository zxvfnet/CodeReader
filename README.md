# QR・バーコード読み取り（CodeReader）

画像に写った複数の QR コード・バーコードを読み取り、Excel で開ける CSV に保存する Windows 用アプリです。

## 使い方
1. `CodeReader.exe` をダブルクリックして起動します。
2. 画像やフォルダをウィンドウにドラッグ＆ドロップします（「画像を追加」「フォルダを追加」ボタンでも可）。
3. 左の一覧で画像を選ぶと、右上に検出位置、右下に読み取り結果が表示されます。
   - 結果の行をダブルクリックすると内容をコピーできます。
   - 黄色の行は「要確認」です（読み取り値が食い違った、検出数が上限に達した など）。
4. 「CSVに保存」で全画像の結果を1つの CSV に保存します。保存後に Excel で開けます。

## 対応しているもの
- 画像：PNG / JPEG / BMP / GIF / TIFF / WebP（フォルダは直下の画像のみ）
- コード：QR、DataMatrix、Aztec、PDF417、Code128、Code39、EAN-13 など zxing-cpp が対応する形式
- 1枚あたり最大 255 個（超える場合は「要確認」の警告が出ます）

## CSV の列
| ファイル名 | 種別 | 読み取り内容 | 位置 | 備考 |
|---|---|---|---|---|

文字コードは BOM 付き UTF-8 です。数字だけの値は `="0123"` の形で書き出すため、Excel でも先頭の 0 が消えません。

## exe の作り方（開発者向け）
WinPython Command Prompt でこのフォルダに移動し、`build_exe.bat` を実行します。
`dist\CodeReader` フォルダができるので、フォルダごとコピーして配布します。
詳細は `docs/developer.md` を参照してください。
